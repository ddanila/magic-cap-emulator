# Repository workflow

- This is a personal project. Commit and push useful intermediate results;
  do not leave completed work only in the local checkout.
- Push directly to `main` unless the user asks for a branch or pull request.
  Pull requests are not required for this repository.
- Publishing is allowed only to repositories in the `github.com/ddanila`
  namespace. Never push to, or create pull requests in, upstream repositories
  or any repository outside that namespace.
